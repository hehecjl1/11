欢迎搭建基于 **Astro Content Collections** 的个人站。

## 如何新增文章

1. 在 `src/content/blog/` 新建 `.md` 文件  
2. 填写 frontmatter（`title`、`description`、`pubDate` 等）  
3. 正文使用 Markdown 书写  

## 代码示例

```js
const greeting = 'Hello, Astro!';
console.log(greeting);
```

保存后运行 `npm run dev`，本地即可预览。
